# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

It is a **hub** and carries no rules of its own. Each half of the application has its own
guidance file, and both are imported at the bottom so they apply in the same session.

| Working on | Rules live in | Covers |
| --- | --- | --- |
| Next.js front-end | [CLAUDE.frontend.md](CLAUDE.frontend.md) | `app-frontend/` — the numbered Critical Rules, Policies, workflow commands |
| .NET back-end | [CLAUDE.backend.md](CLAUDE.backend.md) | `app-backend/` — mandatory `backend-workflow` sub-agent, BDD cycle, manual-test & commit gate |

Neither file overrides the other; each governs its own folder. A change that spans both
follows each file on its own side.
